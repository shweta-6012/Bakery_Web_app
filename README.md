# Bakery_Web_app

A responsive bakery website built to practice **frontend web development, JavaScript, styling, and database integration**.

## ✨ About

The Bakery Web App provides a clean and responsive interface for a bakery website. The project demonstrates the use of core web technologies to build and structure a functional website.

## 🚀 Features

- Responsive bakery website
- Clean and user-friendly interface
- Interactive functionality using JavaScript
- Custom styling with CSS
- SQLite database integration
- Structured frontend project

## 🛠️ Tech Stack

- **HTML5**
- **CSS3**
- **JavaScript**
- **SQLite**

## 📁 Project Structure

- `index.html` — Main webpage
- `style.css` — Website styling
- `main.js` — JavaScript functionality
- `db.sqlite3` — SQLite database
- `README.md` — Project documentation
